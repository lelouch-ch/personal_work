## AI Context

This project maintains an AI-visible knowledge base in `docs/ai-context/`:

- `README.md` - project overview and current status
- `conventions.md` - coding standards, naming, tech-stack constraints
- `decisions.md` - key decisions and rationale (ADR style)
- `requirements.md` - functional requirements and acceptance criteria
- `rejected.md` - tried-but-abandoned approaches
- `changelog.md` - milestone-based change summaries

Read `docs/ai-context/README.md` first, then only the files relevant to the
current task. Keep these files up to date when requirements, scope,
architecture, decisions, or constraints change; organize entries by purpose,
not as a chronological log.
